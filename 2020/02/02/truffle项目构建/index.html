首先使用npm安装truffle

-g是global全局的意思，这样安装后在任意文件夹下都能使用truffle。

然后使用命令行工具进入项目目录，执行指令truffle unbox webpack，下载完项目模板后，目录下会有app，contracts，migrations，test四个文件夹，以及truffle-config.js文件。因为我们要使用自己的私链网络，在truffle-config.js里配置网路，在network节点下配置，

配置文件里已经写好了这一项，只是用注解注掉了。打开注解即可。app是存放前端代码的目录。还可以在compilers结点下配置编译器的版本。我使用的是0.4.26。
其他几个目录：contracts存放的是智能合约代码。migrations存放的是合约部署配置文件，test存放一些测试文件。contract下自带一个代币合约完整演示，app里面有完整的前端代码，我们删除contract下的ConvertLib.sol 和 MetaCoin.sol两个文件。把自己的合约代码放入这个文件夹下。

然后我们要启动自己的私链网络，我使用的是geth，首先初始化创世区块。创建创世区块文件genethesis.json

再在命令行执行geth –datadir datadir init genetheis.json初始化区块。其中datadir是数据目录，保存下来后面要使用。然后启动私链。

私链启动后我们在truffle项目目录下输入truffle console也可以进入web3控制台。这里记录几个常用truffle命令。

  • truffle unbox webpack 下载webpack模板
  • truffle init 初始化truffle项目结构
  • truffle compile 编译智能合约
  • truffle migrate 部署合约
  • truffle execute file.js 执行js文件，一般作为数据引入等等
